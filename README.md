# debate_emotion_analysis
Code repository for Group 3 of UCD's POL42560 module 


Emotional Expression in Presidential Debates: Trump vs Harris
Ciarán Neville, Moisés A. Silva, Sofia Quaglia

Our primary hypothesis (H1) posits that Donald Trump will exhibit higher levels of anger, ag-
gression, and negatively valenced emotional expression compared to Kamala Harris. This ex-
pectation is grounded in prior research that characterizes Republican, and especially populist, candidates
as adopting more confrontational, emotionally intense styles.

We have three different folders with individual analysis of the debate
- Voice
- Video
- Text

The full debate video can be accessed here: https://drive.google.com/file/d/1d3dNyBSXliHWwfkzujKabb-ruXkXS-AS/view?usp=sharing
